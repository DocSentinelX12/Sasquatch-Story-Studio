# Episodes

- `_templates/` contains reusable, valid JSON planning documents.
- `in-development/` contains active episode packages.
- `completed/records/` contains release manifests only after an episode is actually finished.

Use `python3 tools/new_episode.py EP-### "Episode Title"` to create an active package. The example EP-001 is intentionally marked `outline`; it is neither rendered nor completed.
